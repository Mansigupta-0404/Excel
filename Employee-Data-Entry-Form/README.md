# Employee Data Entry Form

## Project Overview
An Excel-based employee data entry application designed to enter,
calculate, and maintain employee information in a structured format.

## Features
- Employee data entry form
- Department selection
- Location selection (Site/Office)
- Salary component entry
- Automatic Net Pay calculation
- Submit button for storing employee records
- Structured employee database

## Departments
- Technical
- Admin
- Accounts
- H.R

## Insights
- Employee records are categorized by department and location.
- Salary is divided into Basic Salary, HRA, Medical, and Conveyance.
- Net Pay is calculated after deductions.
- The form reduces manual data-entry and calculation work.
