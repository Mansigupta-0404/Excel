# 📞 Call Centre Performance Dashboard

## 📊 Project Overview
This project is an interactive Call Centre Performance Dashboard developed using Microsoft Excel.
The dashboard is designed to analyze call centre performance through key metrics such as Working Hours, Active Customers, and Calls Attended.
The project combines Excel Dashboarding, Pivot Tables, Data Analysis, and VBA Macros to create an interactive and user-friendly reporting solution.

## 🎯 Objectives
1. Analyze employee working hours
2. Monitor active customer interactions
3. Analyze the number of calls attended
4. Compare employee performance
5. Create an interactive and automated Excel dashboard
6. Present important business insights in a simple visual format
## 🛠️ Tools & Technologies
Microsoft Excel, Pivot Tables, Pivot Charts, VBA / Excel Macros, Data Analysis, Dashboard Design, Conditional Formatting, Interactive Controls
## ⚙️ Macro / VBA Functionality
The dashboard uses VBA Macros to improve its interactivity and user experience.
The macros are used to perform automated dashboard actions and make the report easier to use.
Macro Features
Automated dashboard interactions
Button-based functionality
Dashboard navigation
Automated actions within the workbook
Improved user experience through VBA automation

Note: The file is saved in .xlsm format because it contains VBA macros.

## 📈 Dashboard Components
### ⏱️ Working Hours
This section analyzes the total working hours of employees.
It helps compare employee availability and workload within the call centre.

## 👥 Active Customers
This section analyzes the Active With Customer metric.
It provides an indication of the time employees spent actively interacting with customers.

## ☎️ Calls Attended
This section analyzes the number of calls attended by employees.
It helps identify employees handling higher call volumes and compare call-handling activity across employees.
